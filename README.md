# Tickr Backend

## Current Tech Stack
- TypeScript
- ExpressJS
- Prisma ORM
- Zod
- Pino

## Features
- Auth (Login, Register, Logout)
- Manage Categories (Admin)
- Manage Tickets
- Assign User Role (Admin)
- Ticket Timelines
- Ticket Comments
